# MicroFrame docs

MicroFrame est un moteur de rendu Jinja2 async. Le point de depart recommande est `guide.md`.

## Parcours recommande

- `guide.md` : flux complet pour demarrer
- `components.md` : composants HTML et microui
- `remote-action.md` : tags distants et formulaires d action
- `micro-frontends.md` : fragments HTTP asynchrones
- `context-processors.md` : injection automatique de contexte
- `cli.md` : rendu, build et scaffold depuis la ligne de commande
- `api.md` : reference complete de l API
- `integration-xcore.md` : integration FastAPI + XCore
- `django.md` : usage du moteur dans Django

## Duree de lecture

Si tu decouvres le projet, lis `guide.md` en premier, puis ouvre la page correspondant a la fonctionnalite que tu veux utiliser.
